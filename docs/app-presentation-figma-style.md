## 7. График прогресса

### Что видит пользователь
- график, который показывает прогресс по тренировкам;
- при изменении значений график обновляется сразу;
- визуально это выглядит как динамическая стрелочная диаграмма прогресса.

### Что отвечает за это в коде
```tsx
const chartData = values.map((value, index) => ({
  x: index,
  y: value,
}));

const linePath = chartData
  .map((point, index) => `${index === 0 ? 'M' : 'L'} ${point.x} ${point.y}`)
  .join(' ');
```

### Где это можно подключить
- [src/features/dashboard/screens/DashboardScreen.tsx](src/features/dashboard/screens/DashboardScreen.tsx)
- [src/features/history/screens/HistoryScreen.tsx](src/features/history/screens/HistoryScreen.tsx)

### Короткое пояснение
Если подключить график к данным из состояния приложения, то при изменении повторений, подходов или целей он будет перерисовываться в реальном времени, создавая эффект живого прогресса.

## 8. Как это выглядит в использовании

1. Пользователь открывает главный экран.
2. Выбирает упражнение.
3. Добавляет тренировку.
4. Видит результат на главной странице.
5. Создаёт цель.
6. Открывает историю и смотрит свои данные по дням.

---

## 9. Короткий текст для презентации

Gym VOVA — это мобильное приложение для отслеживания тренировок, постановки целей и ведения истории прогресса. Пользователь может быстро добавлять результаты, видеть статистику за день и следить за своими достижениями. График прогресса делает интерфейс более живым и помогает визуально ощущать динамику улучшений.
